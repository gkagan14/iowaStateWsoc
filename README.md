# Big 12 Women's Soccer — Scouting Dashboard

A single-file scouting dashboard for the Big 12 women's soccer season, plus the data
pipeline that keeps it current.

**Live site:** GitHub Pages serves `index.html` from this repository.

## What's here

| Path | What it is |
|---|---|
| `index.html` | The dashboard — one self-contained file, no server or internet needed once loaded |
| `big12-soccer-team-stats-2025-2026.csv` | Two-season team stats for staff use in Excel |
| `big12-soccer-game-logs-2025-2026.csv` | Every match for both seasons, with box-score lines |
| `pipeline/` | The scraper and the dashboard source. This is what regenerates everything |
| `.github/workflows/refresh-dashboard.yml` | Monday cron that re-scrapes the season and commits a fresh `index.html` |

## Refreshing manually

```bash
cd pipeline
./refresh.sh              # current season only (~3 min)
./refresh.sh --both       # both seasons (~7 min)
./refresh.sh --skip-fetch # re-render only, after editing part_a.html / part_b.html
cp ../files/big12-womens-soccer-2026-dashboard.html ../index.html
cp ../files/big12-soccer-*.csv ..
```

The script reconciles every team's wins, losses, ties, goals for and goals against against the
Big 12 conference statistics page and prints any mismatch — do not publish a build that
reports one.

## Editing the dashboard

The HTML is generated, never hand-edited:

- `pipeline/part_a.html` — header, styles, conference board, scatter
- `pipeline/part_b.html` — team pages, matchup lab, prep sheet, game explorer, projections
- `pipeline/dashboard_data.json` — the composed data (regenerated by `refresh.sh`)

Edit either part, then `./refresh.sh --skip-fetch` to re-render.

## Data provenance

2026: 222 matches, 221 with full box scores. 2025: 236 matches, 215 with full box scores.
Team totals reconcile to the Big 12 Conference official statistics. Known gap: BYU and UCF
2025 out-of-conference stat lines are scores-only. Method notes are in the dashboard's
"Method & sources" tab.
